## 2. Запушити код

На комп’ютері має бути Git. Увійди на github.com як `orbitsnetwork-rgb`.

1. Завантаж `ORBIT_CODE.zip`.
2. Розпакуй у порожню папку, наприклад `orbit`.
3. Відкрий термінал у цій папці.
4. Виконай:

```
git init
git add .
git commit -m "Орбіти: поточний код"
git branch -M main
git remote add origin https://github.com/orbitsnetwork-rgb/orbit.git
git push -u origin main
```

5. Якщо питає вхід — увійди як `orbitsnetwork-rgb`.
6. Відкрий https://github.com/orbitsnetwork-rgb/orbit і переконайся, що там є `package.json` і папка `src`.

Якщо пише `remote origin already exists`:

```
git remote set-url origin https://github.com/orbitsnetwork-rgb/orbit.git
git push -u origin main
```

## 3. Підключити хостинг

Новий хостинг, не старий Railway. Нова адреса має початися з порожнього світу.

1. Зареєструйся на Railway або Vercel на пошту проєкту.
2. Зареєструйся на Railway на пошту проєкту.
3. New project → Deploy from GitHub → репозиторій `orbitsnetwork-rgb/orbit`, гілка `main`.
4. Railway прочитає `railway.toml`: збере `npm run build:host`, запустить `npm run start`.
5. Додай змінну `DATABASE_URL` від Postgres цього ж проєкту.
6. Дочекайся адреси. Відкрий її. Має бути вхід Орбіт і порожній світ.

Адресу запиши собі. У чат можна надіслати тільки адресу, без паролів.

---

## 4. Підключити тестове поповнення

Тільки тест. Бойові ключі не створювати.

1. Зареєструйся в Stripe на пошту проєкту.
2. Увімкни тестовий режим.
3. Візьми тестовий секретний ключ. Він починається на `sk_test_`.
4. У хостингу додай змінну:

```
STRIPE_SECRET_KEY=sk_test_...
```

5. У Stripe створи webhook на адресу:

```
https://ТВОЯ-АДРЕСА/api/stripe
```

Подія: `checkout.session.completed`.

6. Секрет webhook починається на `whsec_`. Додай другу змінну:

```
STRIPE_WEBHOOK_SECRET=whsec_...
```

7. Перезапусти сервіс, щоб змінні підхопились.
8. На сайті зайди в «Я» і натисни «Поповнити». Має відкритися тестова оплата Stripe.
9. Картка в базу не пишеться. Після успішної тестової оплати баланс ОД має зрости.

Поки цих двох змінних немає, кнопка чесно каже, що тест не підключено.

## 5. Що не чіпати

- Шанс заряду, ціна, поділ 97 / 2,5 / 0,5, фонд раз на 3 доби, старт 200 ОД.
- Файл `src/lib/orbit/engine.ts` без окремого запису в базі.
- Бойовий режим Stripe.
- Дані картки. Їх немає в базі і не треба додавати.
- Старі доступи.

1. Пуш коду в `orbit`.

6. Перевірка картки і виведення — після тесту, не раніше.

Паролі в базу проєкту не писати. Доступи тримай у себе окремо.
